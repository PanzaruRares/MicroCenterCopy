## 📌 Project Overview

This repository contains a full-stack web application designed to replicate the core browsing, shopping cart, and user authentication workflows of an e-commerce platform modeled after Micro Center.

The primary goal of this project was to practice building a modern web application  paired with lightweight Node.js backend workflows and Supabase APIs for user authentication and relational database services.

---

## 🛠️ Tech Stack

- **Frontend:**
  - **HTML5** – Semantic structure and accessible markup
  - **CSS3** – Responsive layouts, flexbox, grid, and custom styling
  - **JavaScript (ES6+)** – DOM manipulation, event handling, and API integration
- **Backend & Database:**
  - **Node.js** – Server-side environment and API routing
  - **Supabase** – Authentication (Auth API) and backend database management

---

## ✨ Key Features

- **🔐 User Authentication:** User signup, login, and session management powered by Supabase Auth APIs.
- **🛍️ Product Browsing:** UI replica of product categories, listings, and item detail views.
- **🛒 Shopping Cart:** Interactive cart functionality to add, update, and remove products in real time.
- **📱 Responsive Layout:** Clean, mobile-friendly interface designed with CSS.
